Bienvenido

Facilitar el registro inicial de animales que llegan al refugio, organizar los datos esenciales de cada caso y ofrecer una consulta sencilla de los rescates ingresados.

El prototipo está dirigido a un refugio que recibe reportes de perros, gatos y ejemplares de fauna silvestre. La página de inicio presenta el propósito del sistema y orienta al usuario hacia las funciones principales. La página de registro reúne los datos mínimos para identificar el caso y describir las condiciones en que fue encontrado el animal. Finalmente, la página de rescates presenta una relación organizada de casos de ejemplo, lo que permite revisar rápidamente su categoría y prioridad.

¿Cómo utilizar el prototipo?

Registrar un caso

Ingrese a la opción «Crear reporte» y complete los campos disponibles con la información conocida del animal.

Consultar información

Acceda a «Consultar registros» para revisar los casos de demostración organizados en una tabla.

Alcance de esta versión

Esta entrega corresponde a una estructura HTML5. No almacena datos en una base de datos ni utiliza hojas de estilo CSS o programación JavaScript.
